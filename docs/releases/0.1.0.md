# 0.1.0

Première version de W3DTS ChessMaster.

La partie se joue sur une table en 3D. On peut jouer contre l’ordinateur, à deux avec la même souris, ou à deux fenêtres sur ce poste. Une courte ouverture sert à apprendre une ligne. L’image se règle du plus fluide au plus détaillé. L’interface propose huit langues, et le français est celle de départ.
